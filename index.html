HELP — LIMITAÇÕES REAIS

Bluetooth: o navegador não controla o Bluetooth. O áudio vai para a saída padrão do Android. Se a caixa estiver pareada, o som sai nela — mas o app não consegue escolher o codec, nem medir/compensar a latência do Bluetooth. Use setSinkId (abaixo) se disponível.

Echo Cancellation: depende do Android/Chrome. Aplicamos a restrição echoCancellation:true, mas o processador pode ser do próprio sistema. Não há garantia de eliminar toda microfonia.

Noise Suppression: idem — é um recurso do sistema operacional, ligado/desligado via restrição. Não há controle de intensidade.

Feedback Reduction: implementação heurística via FFT + filtros peaking. Funciona bem para microfonia tonal sustentada; não é um supressor profissional (que usa deslocamento de frequência e detecção adaptativa por hardware).

Gate: usa AudioWorklet com detector de envelope, hold e release — não corta o início das palavras porque o attack é aplicado na abertura e o hold mantém o gate aberto.

Segurança: um soft-clip após o master garante que nada ultrapasse 0 dBFS. Ainda assim, comece com o master baixo para evitar realimentação.
